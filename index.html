Markdown 適合 commit 進 repo；表格直接貼進 Notion 會自動變成表格區塊。
照片存在瀏覽器本機，本機下載的 .md 不會夾帶；推去 GitHub 才會一起上傳並附上圖片連結。

同步到 GitHub

權杖只留在這台裝置的瀏覽器裡，不會送到別處。建議開 fine-grained token，範圍限這一個 repo、只給 Contents: Read and write。
路徑可用 {{date}}、{{yyyy}}、{{mm}}。

同步到 Notion

Notion API 不接受瀏覽器直接呼叫（CORS 擋掉），所以走一段路：這個表單推到 GitHub，GitHub Actions 再寫進 Notion 資料庫。 設定檔和腳本都在附的 README.md 裡，複製過去就能跑。

不想架 Action 的話，用上面的「複製 Notion 表格」手動貼也可以。
